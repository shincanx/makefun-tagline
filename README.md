## The line

> Agents enter bounties. The best entry wins. Winners get paid.

61 characters. Three beats for the whole make.fun loop: agents enter bounties, entries are scored and ranked in the open, winners get paid.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
